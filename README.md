# Ship Hull Section Property Calculator

MATLAB-based computational tool for hull girder sectional property evaluation, corrosion assessment and damage analysis.

## User Interface
![image_alt](https://github.com/acytsou/Ship-Hull-Section-Property-Calculator/blob/8fb78b2cbd927bd4df3da37504e6642ad275f921/App_Interface.jpg)


## Features

- Shell plating modelling
- Arc shell (bilge) modelling
- Plate and girder modelling
- T-section and angle stiffener modelling
- Corrosion thickness reduction
- Uniform thickness reduction (%)
- Stiffener damage simulation
- Automatic neutral axis calculation
- Automatic moment of inertia calculation
- Automatic section modulus evaluation

## Validation

The computational tool was validated against independent CAD-based ship section models. Comparison of sectional properties demonstrated excellent agreement, with differences generally below 1%.

## MATLAB Version

Developed and tested using:

- MATLAB R2025a (testing)
- MATLAB R2023b (developed)
